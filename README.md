# FF GLORY Website

Static front-end website preview.

## Run
Open `index.html` in a modern browser. Keep `style.css`, `app.js`, and `background.mp4` in the same folder.

## Updates included
- Added a muted, looping background video layer (`background.mp4`).
- Added Diamond Top-Up packs: MONTHLY ₹200, 5 WEEKLY VIP ₹400, 1000 DIAMOND ₹600, 5000 DIAMOND ₹1000.
- Added a redesigned payment scanner preview panel. The QR shown is decorative only; replace it with your verified payment QR before use.
- Kept the existing Add Funds section and its values unchanged.

## Important
This is a front-end demo. Login, scanner, top-ups, and payment actions are not connected to a real backend or payment provider. Do not use the decorative QR pattern to collect payments.
